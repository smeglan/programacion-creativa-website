# Programación Creativa · Landing

Landing sencilla para la clase de **Programación Creativa**.

Incluye:

- Enlace al **grupo de WhatsApp** de la clase.
- Enlace al **repositorio** de la clase en GitHub.

## Stack

- Vite
- React + TypeScript
- CSS propio (animación generativa en `canvas` como fondo)

## Scripts

- `npm run dev` — servidor de desarrollo
- `npm run build` — build de producción
- `npm run lint` — lint
- `npm run preview` — vista previa del build
